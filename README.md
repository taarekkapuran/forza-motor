Forza Motor adalah website satu halaman untuk showroom motor mewah yang menampilkan empat unit: Ducati Panigale V4 R, Harley-Davidson CVO Road Glide ST, Aprilia Tuono V4 Factory, dan KTM 300 EXC Hard Enduro. Halaman ini terdiri dari hero pembuka, daftar koleksi dengan empat angka kunci tiap motor (kapasitas mesin, tenaga atau berat, dan tinggi jok), bagian keunggulan showroom, serta formulir permintaan test ride. Setiap motor punya tombol “Lihat spesifikasi” yang membuka jendela berisi data lengkap, mulai dari mesin, sasis dan suspensi, dimensi, sampai fitur. Data tersebut diambil dari situs resmi masing-masing pabrikan, dan tautan sumbernya ada di setiap jendela. Tampilannya mengusung konsep lantai showroom yang terang, dengan warna aksen tiap baris mengikuti warna motornya.

Website ini dibuat dengan HTML, CSS, dan JavaScript murni tanpa framework. HTML menyusun struktur halaman, CSS (Grid dan Flexbox) membuat tampilan responsif dari layar HP sampai desktop, dan JavaScript menyimpan data spesifikasi, menampilkan jendela spesifikasi dengan elemen <dialog>, serta memvalidasi formulir test ride. Foto motor sudah dipotong dan dikompres ke format WebP supaya halaman cepat dimuat, dan animasi otomatis dimatikan bagi pengguna yang mengaktifkan pengaturan reduce motion. Untuk menjalankannya, cukup buka index.html di browser. Formulir test ride saat ini masih berupa demo tampilan dan belum mengirim data ke server.
